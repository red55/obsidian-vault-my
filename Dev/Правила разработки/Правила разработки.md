## Все языки

1. Если разработка начинается с 0, берутся самые последние версии ЯП, библиотек, фреймворков и т.п.
2. Исходники сканируются trivy, CRITICAL, HIGH - обязательны к исправлению. Если на момент обнаружения не существует фикса, в системе управления тербованиями/задачами должно быть заведено соответсвующее Issue, в коде/файле настройки сканнера должен быть комментарий, содержащий дату и причину отключения. Например: "2026-12-11 no known fix for now"
3. Commit message должны соответсвовать [Conventional Commits] (https://www.conventionalcommits.org/en/v1.0.0/). Настроен [pre-commit](https://pre-commit.com/), [conventional-pre-commit](https://github.com/compilerla/conventional-pre-commit)
4. Коммиты, сделанные ИИ должны быть помечены [`Co-Authored-By`](https://github.com/sinelaw/fresh/commit/1b40ad4643f3969dde19fd1d6bfc32e550ca7be7).
5. Комментарии к членам классов/функиям/переменным пишем в форма, понятом для IDE, что бы при автодополнении был виден коментарий. Класс/переменная с настройками приложени __ОБЯЗНЫ__ иметь такие комментарии


***.pre-commit-config.yaml:***

```yaml
repos:
	- repo: https://github.com/compilerla/conventional-pre-commit
	  rev: v4.4.0 # Use the latest available version
	  hooks:
		  - id: conventional-pre-commit
		    stages: [commit-msg]
```
